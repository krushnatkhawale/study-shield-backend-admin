# StudyShield Admin

[![CI](https://github.com/krushnatkhawale/study-shield-backend-admin/actions/workflows/ci.yml/badge.svg)](https://github.com/krushnatkhawale/study-shield-backend-admin/actions/workflows/ci.yml)

Vaadin 24 console for the StudyShield backend: boards, classes, subjects, packs, quizzes
and the question bank.

```bash
./gradlew :app:bootRun
```

http://localhost:8081/login

**Documentation** (run instructions, operator flow, feature map) lives in the aggregated
docs site: https://github.com/krushnatkhawale/study-shield-docs → `docs/per-repo/admin.md`
(locally: `REPOS/study-shield-docs`, then `./scripts/serve.sh`). See `docs/README.md` here
for the pointer map.
